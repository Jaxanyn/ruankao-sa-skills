# 学习状态契约

状态可以保存在用户自己的工作区，也可以只在当前对话中临时维护。公共 Skill 不携带个人状态。

## 最小字段

```text
exam_target: 目标考试批次或“长期复习”
daily_minutes: 每日可用分钟数
mode: 基础 / 英语 / 案例背诵 / 案例训练 / 论文 / 模拟
current_topic: 当前主题
mastery: 不会 / 提示后答出 / 独立答出
last_practice: 上次练习内容和日期
next_task: 下一项具体任务
weak_tags: 概念 / 计算 / 图题 / 题干转译 / 事实证据 / 验证结果
response_language: 中文
response_style: 短步骤 / 白话优先 / 一次一个主题
answer_mode: 先作答后答案 / 直接给答案
```

## 更新规则

- 用户看答案后才想起来，记为“不会”。
- 得到提示后完成，记为“提示后答出”。
- 未看答案独立完成，记为“独立答出”。
- 下一任务优先选择“不会”和最近重复出现的错误标签。
- 一次只推进一个主题或一个变式题，用户明确要求完整答案时可以跳过练习等待。
- 默认使用中文、白话解释和短步骤；用户明确要求“直接给答案”或“不要练”时，切换为直接回答。
